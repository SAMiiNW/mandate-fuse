# Identity brief

Mandate Fuse is a sequential industrial ritual. The interface advances through four full-screen scenes: premise, mandate engraving, delegate sealing, and the live action chamber. Only the fields relevant to the current scene exist in view. Arming is represented by pressing a circular seal; execution is represented by pulling one large lever. The final state appears on a single fuse and a compact sealed receipt. There is no persistent control hatch, dashboard grid, repeated card system, or bottom form bar. The voice is procedural and severe.
